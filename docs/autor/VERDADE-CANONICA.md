# Verdade canônica — índice reservado do autor

> Este índice não integra o site. O diretório `docs/autor/` é uma fronteira editorial e técnica.

As verdades reservadas permanecem em [`SEGREDOS-DO-AUTOR.md`](./SEGREDOS-DO-AUTOR.md), [`GENEALOGIAS-SECRETAS.md`](./GENEALOGIAS-SECRETAS.md) e [`REGISTROS-RESTRITOS.json`](./REGISTROS-RESTRITOS.json). Este arquivo não repete seus conteúdos: ele define como essas fontes se relacionam ao cânone publicável.

## Ordem de autoridade

1. Decisão direta e datada do autor.
2. Lore canônica consolidada e fatos centrais já publicados.
3. Registro reservado explicitamente classificado.
4. Expansão editorial coerente, sempre subordinada aos níveis anteriores.
5. Rumor, versão cultural, profecia e documento contestado — nunca promovidos por inferência.

## Promoção ao acervo público

Antes de revelar uma verdade reservada:

1. registrar a autorização e a data;
2. remover ou atualizar a lacuna pública correspondente;
3. revisar busca, SEO, Atlas, genealogias, sucessões e relações recíprocas;
4. verificar cronologia, portadores, locais e consequências;
5. executar `npm run validate`, `npm run lint` e `npm run build`;
6. confirmar que nenhum outro segredo foi exposto por associação indireta.

Nenhum segredo central foi promovido automaticamente durante este aprimoramento.
